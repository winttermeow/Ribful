# RIBFUL

### 🎮 About the game

Ribful is a platformer developed on the Unity engine and inspired by games like «Celeste», «Super meat boy» and «IWBTB». Everything created by me.

We have [our own discord server](https://discord.gg/96dJFkJXYz) that you can join. Here's a couple of benefits you're getting by joining it:
